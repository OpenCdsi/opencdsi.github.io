 I've added a demonstration app to the OpenCdsi project. It is an Android,
 off-line first vaccine forecasting tool for clinicians.

 I was really excited the first time this thing ran on my Android phone.
 It is a mid-tier Motorola, a Moto Stylus 5G 2026, and has no
 problem forcasting given a patient with an immunization history.

 This app is an MVP, minimum-viable-product. It has no sync capability,
 no way to update the antigen schedules, no way to report bugs or ask for
 features. But it works!
